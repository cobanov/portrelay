Capabilities & connection details
  • Encrypted USB sharing on Linux and Windows; physical compatibility is still being tested.
  • Focused keyboard and mouse control to an unlocked Linux desktop, with separate permission.
  • Limited Mac USB export. Mac USB receiving and Bluetooth are unavailable.
  • GitHub account discovery, optional offline pairing, and per-device permissions.
  • Whole USB Bluetooth adapter handoff is experimental. Individual Bluetooth profiles are unavailable.
