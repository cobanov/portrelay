Settings & status

Available in this alpha

  • Linux and Windows USB sharing with encrypted connections.
  • GitHub sign-in, automatic computer discovery, and account device removal.
  • Optional offline pairing, device permissions, and owner disconnect.
  • Keyboard and mouse control from this window to an unlocked Linux desktop, with separate permission.
  • Input devices, idle disks and disabled USB network adapters, with handoff warnings.
  • Hub device groups and a Bluetooth adapter pairing guide.
  • Internet connections with a configured relay.

Physical USB and Bluetooth compatibility still need testing. The Mac development preview can export eligible single-interface devices. Mac USB import and Bluetooth remain unavailable.
